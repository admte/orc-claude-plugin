# ORC8R for Claude

This plugin connects Claude to ORC8R Cloud through the remote MCP server at `https://orc8r.com/mcp`. It includes a skill that helps Claude find operations, inspect their inputs, and report results. After installing the plugin, connect the ORC8R connector and sign in through OAuth. ORC8R grants read access and lets you select write access, subject to your existing organization permissions. No credentials are included in the plugin.

## Privacy

[Privacy](https://orc8r.com/privacy) explains how ORC8R handles data sent to its service through the connector.

## Support and terms
